# 5. Two colour tokens tuned for contrast

Status: accepted (plan §7.2 says to tune on a phone)

A contrast test checks every text colour against paper, surface and leaf. Two starting
values missed 4.5:1 on the leaf colour: light `neem` (#2F6B4F → #2C6449) and dark `kumkum`
(#E07A6E → #E5837A). The changes are the smallest that pass.
